# web/src/views 模块说明（粤语版）

## 呢个模块做咩

`views` 系前端一页页画面嘅「铺面」。登录页、首页、错误页、占位页，都放喺呢度。

## 调用关系

```text
router
  -> 匹配 URL
  -> 加载 views 入面嘅页面组件
  -> 页面调用 stores / api
  -> 渲染结果畀用户睇
```

## 入参

| 来源 | 说明 |
| --- | --- |
| 路由参数 | URL 决定显示边个页面 |
| 用户输入 | 登录表单、按钮点击 |
| store 状态 | 登录状态、用户资料 |
| API 响应 | 后端返回数据 |

## 出参

| 输出 | 说明 |
| --- | --- |
| Vue 页面 | 用户实际睇到同操作嘅界面 |
| API 调用 | 页面触发数据请求 |
| 路由跳转 | 登录成功、访问错误页等 |

## 通俗比喻

`views` 就似商场入面一间间铺：登录页系前台，Dashboard 系办公室，404 就系「呢间铺搬咗」嘅提示牌。
