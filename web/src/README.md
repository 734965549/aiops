# web/src 模块说明（粤语版）

## 呢个目录做咩

`web/src` 系前端源码嘅「营业大厅」。页面、路由、状态、接口请求、样式入口都喺呢度。

## 调用关系

```text
main.ts
  -> App.vue
  -> router
  -> views 页面
  -> stores 状态
  -> api 请求后端
  -> styles 全局样式
```

## 入参

| 来源 | 说明 |
| --- | --- |
| 浏览器 URL | 决定进入边个页面 |
| 用户输入 | 登录表单、按钮操作 |
| 后端 API | 返回 token、用户资料、系统数据 |

## 出参

| 输出 | 说明 |
| --- | --- |
| 渲染页面 | 用户最终见到嘅界面 |
| API 请求 | 发到后端 |
| 前端状态 | token、用户信息、路由状态 |

## 通俗比喻

`src` 就似餐厅前厅：有餐牌、收银、座位安排、服务员，每一样都配合先可以顺利服务客人。
